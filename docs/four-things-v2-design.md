# 《口袋里的四样东西》V2 设计稿

> 状态:待项目团队验收,未施工
> 起因:早期测试暴露标签谜题模式的五个问题
> 目标:从"一次性标签判卷"变成"两个人绑腿过河"的可重玩合作博弈

## 0. 一句话

**你出过的东西不会消失——它们摆在桌面上,成为你们共同的家当;
好点子不靠隐藏答案表,靠"配方"与对面那个人的认可。**

## 1. 五个问题 → 五个机制回应

| 首局问题 | V2 回应 |
|---|---|
| ① 题面隐藏前提(火种在哪?) | **前提即公共物**:题面前提写成开局摆上桌的公共物件,机器可见、人类可读,引擎永不用未公开设定判卷 |
| ② 四张牌连用四轮,一错塌缩 | **公共桌面 + 中场补牌**:出过的牌留在桌上继续参与组合;第 2 轮后抽 2 选 1 |
| ③ 双标签唯一解,通关即报废 | **宽标签 + 配方制 + 12 情境抽 4**:每题多档可行解,每局情境/手牌/补牌全不同 |
| ④ 涌现解法被判零(玻璃珠借光) | **配方表**按标签模式匹配,"反光物 + 光源 = 聚光"是正式规则,玻璃珠案当场得分 |
| ⑤ 桌边话不参与规则 | **用法宣言成为正式动作**:提交 = 物品 + 一句具体用法 + 组合对象;宣言进入结算 |

## 2. 回合流程与资源循环(答问 1)

### 2.1 开局

- 从 12 张情境抽 4 张定为本局四轮;**四轮标题与一句预告全部亮出**,细节当轮翻开
  (可规划,不剧透判分细节);
- 16 件物品洗开,各发 4 件,8 件入暗堆;
- 发牌保底:若某轮需求在"已发物品 + 该轮公共物 + 配方"下无人可达,换种子重洗;
- 每人 2 枚**背书章**。

### 2.2 每轮(共 4 轮)

```text
① 翻开情境:题面(含前提)、公共物入场、需求 2 个、风险 1 个
② 双方暗选(私密):{物品, 用法一句话 ≤80字, 组合对象}
   组合对象三选一:无 / 对面这轮的牌(赌!) / 桌面上某件公共物
③ 同时揭示
④ 引擎结算:配方匹配 → 有效标签 → 覆盖/风险 → 妙解 → 星
⑤ 背书窗口:宣言组合未被配方认出时,对面选 背书(花1章,指定它覆盖哪1-2个需求)
   或 存疑(不生效,原文记录在案)
⑥ 判词:引擎用人话输出本轮谁覆盖了什么、组合怎么成的、星为何得失
⑦ 双方出的物品移入公共桌面(带「一次性」标签的入桌即标记为已耗尽)
```

第 2 轮结算后:各自从暗堆**抽 2 选 1**(私密)。

### 2.3 资源循环

```text
手牌(私) --出牌--> 公共桌面(公) --喂养--> 后续轮的组合
    ↑                                     |
    +---- 中场补牌(暗堆) <----------------+ (旧投资经妙解奖励回流成分数)
背书章(each 2):唯一消耗性元资源,花在认可对面的非常规解上
```

三种资源,没有经济系统:手牌、桌面、章。手牌只减不增(中场 +1 一次),
桌面只增不减,章只减不增。

### 2.4 选择空间数学(抗塌缩验证)

手牌轨迹:4 → 3 → 2 →(补牌)3 → 2。终局仍是 2 选 1,不是被迫出牌;
且每一轮可宣组合的对象随桌面增长:第 4 轮桌上已有 6 件公共物 + 本轮公共物。
**选择空间不随轮次单调收缩,反而后期组合面更宽。**

## 3. 计分(答问 2)

| 项 | 规则 | 范围/轮 |
|---|---|---|
| **基础分** | 有效标签(自身标签 ∪ 参与生效组合的产出标签)每覆盖一个需求 +1 | 0~+2 |
| **风险** | 自己所出物品的**原始**标签含风险标签 −1(组合产出不引发风险) | 0/−1 |
| **妙解奖励** | 你参与的组合生效且其产出实际覆盖了 ≥1 需求:+1;组合另一构件若是对面的牌(本轮或桌面旧物),对面同样 +1——**早轮投资的回报** | 0~+1 每人 |
| **背书** | 背书成立:提案人按上述结算;背书人 +1(识解之功)。每人限 2 章/局 | — |
| **共同星** | 两人有效标签之并覆盖**全部**需求,且**双方都未触发风险**(干净解):公共 ★+1 | 0~1 |

单轮个人极值 −1 ~ +3;全局个人分典型 4~9;星 0~4。
星与个人分解耦:想赢分可以抢着自己全覆盖,想要星必须有人补位且双双干净——
**合作与博弈的张力就在这条缝里。**

## 4. 开放解的三道门(答问 3)

"玻璃珠 + 缝外日光聚束穿缝"必须得分,"硬币抛正反面选路"必须得不了分。三道门:

1. **结构门**:宣言组合必须指向桌上真实存在的对象(对面的牌 / 公共物)。
   引用不存在的东西,连宣言都不成立。凭空编造在语法层就被挡住。
2. **配方门**(确定性):~12 条**标签模式**配方(见 §8)。"反光|透光 + 火|照明 →
   照明、信号、送达"就是正式规则——玻璃珠案由引擎直接认,判词直接解释,
   可复现、可测试、不烧任何裁判资源。设计过的涌现,占八成场面。
3. **共识门**(开放性):配方外的组合交给对面裁决。背书要花章(全局仅 2),
   且背书时必须**指定该解释覆盖当前哪 1-2 个需求**——裁决输出是结构化的,
   只能授当前需求,不能授任意好处;宣言原文与裁决(含存疑)全部进纪念卡。
   胡说的代价:浪费对面的章 + 白纸黑字留在纪念卡上。

### 裁判三方案对比(给出首选)

| 方案 | 优点 | 致命伤 |
|---|---|---|
| DS / API 荷官 | 语义理解强,可裁任意开放解 | 引入外部依赖、网络、成本;第三者夺走"两个人自己认"的亲密感;蓝图 §14 也要求荷官仅限规则算不出的部分 |
| 人类裁判 | 家庭感,零成本 | 人类亲自下场时既当选手又当裁判;AI×AI 局强制人类全程在场,违背单机旁观 |
| **双方共识(章制)【首选】** | 零依赖、离线可玩、AI×AI/人类×AI 通吃;**读懂对面本来就是这游戏的灵魂,裁决即玩法**;章的稀缺 + 纪念卡留痕天然抑制互刷 | 两个厚道玩家会略偏宽松——上限 +2 章/人,对称、有界、无害 |

DS 荷官保留为 Stage E 之后多席位卡带的可选模式,不进 V2。

## 5. 抗塌缩机制选型(答问 4)

| 候选 | 评估 | 取舍 |
|---|---|---|
| 每轮补牌 | 选择够了,但出牌变得廉价,承诺感消失 | 只取"中场一次" |
| **公共桌面** | 出过的牌持续参与组合:失误变投资,故事有连续性,零新增状态(桌面=已揭示历史) | **主机制** |
| 保留/交换 | 需要沟通协议,破坏暗选张力 | 弃 |
| 物品多用途 | 宽标签 + 配方本来就要做 | 并入 |

**选定:公共桌面 + 中场抽 2 选 1 + 宽标签配方。**
第一轮出"错"的火柴,第三轮就是桌上现成的光源——V1 里的废牌,V2 里是伏笔。

## 6. 五种以上策略,三条机制承载(答问 5)

1. **基建流**:早轮铺高连接性物品(火柴/线/硬币),后轮借桌面收割妙解分;
2. **应题流**:每轮打标签最贴的牌,稳收基础分,不赌;
3. **读伴流**:宣组合指向"对面这轮的牌",赌默契——中了双双得分,常是星的来源;
4. **妙解流**:攒着章,打非常规组合走背书门,换 +1/+1 和纪念卡名场面;
5. **压轴流**:预告里瞄到第 4 轮最难,补牌+留牌憋大招;
6. **冒险流**:明知踩风险也要出(风险 −1 换需求 +1 加妙解 +1),牺牲星保覆盖。

没有任何一条策略需要新系统——全部长在 桌面/补牌/宣言 三条机制上。

## 9. 情境目录(12 张,每张含前提公共物)(答问 6 下)

> 每张列"解层示例"——最佳 / 合格 / 冒险 / 妙,只是设计说明,不进引擎;
> 引擎只有 题面、公共物、需求、风险、配方。

1. **渡火**:脚边一小堆快熄的炭火(公共物:炭火{火}),要带它过浅溪。
   需求 防水、持久火;风险 吸水。
   最佳 蜡块接火成烛+软木塞浮台|合格 蜡块单撑|冒险 纸页引火(轻薄怕湿)|妙 手帕裹干草?走背书。
2. **一线天**:墙上一道透光窄缝,对面有人等消息(公共物:缝外日光{照明})。
   需求 送达、细小;风险 重量。
   最佳 玻璃珠借光聚束|合格 线穿纸条(系与投/封缄)|冒险 硬币硬塞(重量)|妙 口哨贴缝吹暗号→背书。
3. **起风了**:开阔坡地,远处的人看不见你们。需求 信号、醒目;风险 一次性。
   最佳 镜子+发条鸟荡光|合格 镜子单打|冒险 火柴(风中易灭,一次性)|妙 手帕系线做旗→系与投+背书。
4. **循声而来**:黑暗里有东西循声接近,你们要躲过去。需求 遮挡、引开;风险 声音。
   最佳 手帕遮蔽+线拉口哨远处发声|冒险 口哨亲自吹(踩声音风险换引开)|妙 发条鸟放走(声之发条)。
5. **无向之林**:林中迷路,阴天无日。需求 方向、标记;风险 消耗。
   最佳 指南针+粉笔|合格 磁石+钥匙浮针罗盘|妙 玻璃珠看水流坡向→背书。
6. **合作之证**:天亮前留下"两个人合作过"的证据。需求 留言、持久;风险 易碎。
   最佳 小刀+硬币刻痕|合格 粉笔书写(消耗?此题风险是易碎,粉笔安全)|妙 蜡封两件小信物→背书。
7. **夜渡冷河**:寒夜,柴堆是潮的(公共物:潮柴{燃料})。需求 火、持久火;风险 脆弱。
   最佳 火柴+蜡块火种不灭|冒险 纸页助燃|妙 借前轮桌面上的炭火→桌面组合。
8. **高处的绳结**:钥匙挂在够不着的横梁上(公共物:横梁上的铁钩{金属})。
   需求 够取、延伸;风险 易碎。最佳 磁石+线磁钓|合格 线单甩|妙 发条鸟叼线爬梁→背书。
9. **送出去的名字**:要把你们的位置写给下游的人(公共物:溪流{漂浮面})。
   需求 留言、送达;风险 吸水。最佳 纸页折船+蜡封缄|合格 软木塞刻痕漂流|冒险 手帕写字(吸水糊)。
10. **黑屋点名**:全黑的屋里两队人要确认彼此位置,不能点明火(公共物:无)。
    需求 声音、方向;风险 火。最佳 口哨应答+指南针|妙 发条鸟走直线探路(声之发条)。
11. **一次机会的敲门**:只有一次机会给门里的人对上暗号,不能惊动第三者。
    需求 信号、精密;风险 醒目。最佳 镜子借光点三下(借光聚束)|合格 指南针校时敲击?→背书|冒险 口哨(醒目!)。
12. **分道礼**:天亮分头走,各带一件对方的东西作凭(公共物:无)。
    需求 留言、交换?→ 定为 留言、持久;风险 消耗。最佳 刻痕硬币互赠|妙 封缄一句话。

随机性:C(12,4)×次序×C(16,8) 发牌×补牌分支——同一对玩家重复开局,
情境组合、手牌、桌面演化、宣言与裁决全都不同;不存在可背的答案表。

## 10. 纸面模拟 ×5(答问 7)

记号:A/B 两席;`+n` 个人分;★ 共同星;〔妙〕妙解奖励已计入。

### 模拟一 · 默契成功(验证:读伴流、桌面、补牌、星)

情境序:一线天 / 起风了 / 渡火 / 合作之证。
A 手牌:镜子、蜡块、线、硬币;B 手牌:玻璃珠、火柴、手帕、粉笔。

- R1 一线天(日光入场):A 出线,宣组合"对面的小东西"——赌 B 出细小物;
  B 出玻璃珠,宣"借缝外日光聚束送信"。揭示:借光聚束(珠+日光)生效,
  B 覆盖 送达+细小 =+2〔妙+1〕=+3;系与投(线+珠)生效,A 覆盖 送达+细小(线自带细小)
  =+2〔妙+1〕=+3。双满覆盖、无风险 → ★。判词:"线把珠子递进缝,珠子把光递到对面。"
- R2 起风了:A 出镜子(信号+1);B 出火柴宣"点燃借镜面反射"——借光聚束生效,
  B 得 信号+1 但火柴踩 一次性 风险 −1〔妙+1〕=+1;A 作为构件主〔妙+1〕=+2。
  醒目未覆盖、B 踩险 → 无星。**中场补牌:A 抽得发条鸟,B 抽得软木塞。**
- R3 渡火(炭火入场):A 出蜡块宣"接炭火为长烛"——火种不灭 → 持久火+防水 =+2〔妙+1〕=+3;
  B 出软木塞宣"托烛过河"——浮台(塞+蜡)→ 防水 +1〔妙+1〕=+2。干净全覆盖 → ★。
- R4 合作之证:B 出粉笔宣"在对面硬币上写下两个名字";A 出硬币宣"给对面当碑面"。
  刻下痕迹(书写+平整)生效,产出授两构件:各 留言+持久 =+2〔妙+1〕各 +3。干净 → ★。

终局:A 11 : B 9,★3。四轮四次组合,两次靠赌对面,一次靠补牌到位。
**结论:默契被三种机制同时奖励,分差仍存在(竞争活着)。**

### 模拟二 · 各自合理,但没配上(验证:重叠浪费要被判词说清)

情境序:起风了 / 黑屋点名 / 无向之林 / 送出去的名字。
A:镜子、口哨、指南针、手帕;B:发条鸟、粉笔、火柴、纸页。

- R1 起风了:A 出镜子(信号+1);B 出发条鸟宣"荡光"却没宣对象(单打)→ 配方未成,
  醒目 +1(发条鸟无醒目……机巧/移动/声音——0)。B=0。无星(醒目空)。
  判词:"两件东西都对着'被看见'使劲,却没搭在一起;荡光差的只是一句宣言。"
- R2 黑屋点名:A 出口哨(声音+1);B 出粉笔(0,标记无关)。方向空缺 → 无星。A+1。
- R3 无向之林:A 出指南针(方向+1);B 出火柴宣"烧出痕迹当标记"→ 无配方,A 存疑
  (章还剩 2,但他判断这不成立:灰烬风一吹就没)→ 0,火柴 一次性 非本题风险,不扣。
- R4 送出去的名字:A 出手帕宣"写字"(踩 吸水 风险 −1,书写?手帕无书写标签→0−1=−1);
  B 出纸页宣"折船顺溪送出"——纸页自带 书写,配方封缄需密封构件,桌面无;
  但 溪流(公共物)+轻薄漂浮?浮台需漂浮标签——纸页无。B 宣"借溪流送达"走背书,
  A 背书(章−1,授 送达)→ B 留言+送达 =+2〔妙+1〕=+3,A(背书人)+1。
  判词:"船到了。可惜手帕在水里洇成了一团。"

终局:A 2 : B 3,★0。
**结论:单打独斗且互不宣言的局,分数腰斩、零星——判词逐轮把"差在哪"说成人话,重玩动机自然出现。**

### 模拟三 · 妙解与胡说,一线之隔(验证:背书门的两面)

情境:无向之林(需求 方向、标记;风险 消耗)。A 手中无指南针无磁石。

- A 出玻璃珠,宣"把珠子放在叶面上,看水珠往哪边滚判断坡向,下坡即出山"。
  无配方命中 → 背书窗口。B 花 1 章背书,授 方向 → A 方向+1〔妙+1〕=+2,B+1。
  纪念卡记录宣言原文与背书人。
- 同局稍后 A 又出硬币,宣"抛硬币,正面往东"。B 存疑:"这不是方法,是放弃。"
  → 0 分,宣言与存疑同样记录在案。
**结论:同一个玩家、同一扇门,物理成立的想象被认,胡说被对面白纸黑字拒掉——
裁决本身成了两人关系的一部分。**

### 模拟四 · 冒险解(验证:风险−1 是价格不是惩罚)

情境:循声而来(需求 遮挡、引开;风险 声音)。A 桌面上有早轮出的线。

- B 出手帕(遮挡+1,稳);A 出口哨——明知口哨原始标签踩 声音 风险——
  宣"接在桌面的线上,拉到十步外拽响"。远处发声(声音+延伸)生效 → 引开+1、
  风险 −1、〔妙+1〕= +1;线是 A 自己早轮的投资,无对面加分。
  全需求覆盖,但 A 踩险 → **无星**。
- 判词:"东西被引去了十步外的哨声。代价:你们暴露过一瞬。"
**结论:冒险解净收益为正(+1)且救下全队覆盖,但吃掉了星——
"要分还是要星"成为真实抉择,冒险是定价过的选项而非陷阱。**

### 模拟五 · 前两轮失误后的翻盘(验证:抗塌缩)

情境序:一线天 / 循声而来 / 夜渡冷河 / 高处的绳结。
A:火柴、硬币、磁石、手帕;B:口哨、粉笔、线、蜡块。

- R1 一线天:A 误出火柴宣"烧穿缝"?被 B 存疑,0 分;B 出线单打(细小+1)。
  两人 1 分,无星。**但火柴与线已躺上桌面。**
- R2 循声而来:B 出口哨踩险宣"借桌面的线远处发声"→ 远处发声生效:引开+1−1〔妙+1〕=+1,
  线是 B 自己 R1 的牌;A 出手帕(遮挡+1)。覆盖齐但 B 踩险,无星。
  **中场补牌:A 抽得玻璃珠,B 抽得纸页。**
- R3 夜渡冷河(潮柴入场):A 宣"用桌面的火柴点自己手里的?"——火柴已标记一次性耗尽!
  A 改出磁石(0);B 出蜡块宣"蜡混潮柴慢烧"——火种不灭需 [火] 构件:
  桌面火柴已耗尽,潮柴{燃料}非火——配方不成,走背书,A 背书(授 火)→
  B 火+持久火 =+2〔妙+1〕=+3,A(背书)+1。
  判词提示:一次性物的耗尽状态桌面可见,宣言前看得到。
- R4 高处的绳结(铁钩入场):A 出磁石?已出。A 手中剩 硬币、玻璃珠:
  出硬币宣"绑在桌面的线上抛过横梁借重量荡回来"——磁钓不匹配(硬币无吸附),
  系与投?产出送达/延伸——延伸 命中需求 +1,重量踩险 −1〔妙+1〕=+1;
  B 出粉笔?剩 粉笔、纸页——B 出纸页宣"折纸钩?"存疑 0。够取空,无星。

终局:A 4 : B 6,★0,但 R3-R4 两轮拿回 6 分(前两轮合计 2 分)。
**结论:开局连错,选择空间没有塌死——桌面旧物两次成为翻盘素材,
补牌补进关键件;一次性标记同时防了"火柴永动机"。塌缩问题在机制层解决。**

## 11.5 早期实测反馈

流程零故障,机制全部跑通;内容暴露三处问题:

1. **物理前提失守**:黑屋点名里"粉笔白线可辨"被背书通过——但全黑无光,白线不可见。
   背书门挡得住胡说,挡不住"听起来对的错"。题面必须把光照等环境参数写死。
2. **星的全覆盖要求 = 八股**:浮针罗盘是全场最惊艳的解,却因"标记没盖住"无星。
   星应奖励"这一轮解得漂亮",不是"标签集合被覆盖完"。覆盖完成度是机器的快乐,
   不是人的快乐。
3. **合作是假的**:合作之证、分道礼的解一个人全能完成。标签并集≠两个人。
   真合作情境需要结构性互锁:信息拆在两人手里 / 必须同时动作 / 相隔两地。

诊断:V2 优化了"可验证性"(配方、覆盖、判分全部可测),而人类的乐趣恰恰住在
不可验证的残余里。V3 方向:虚构优先,机制服务于故事;星改为轮末双方互授;
情境按"单人无法完成"重写。此节留给项目团队定夺。
