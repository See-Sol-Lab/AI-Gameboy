# 夜铺 · 旧物与等它的人（草稿第二版，待莉莉丝审）

规则草案：客人**第一次**买到**修满的那一件**时，多说一句台词，并额外道谢（多付一份谢礼）。之后再买到同一种，不再说。没修满的照常成交，没有反应。

配对原则：物品类别必须在客人收货的类别里；台词要能接上这件旧物修满后的秘密，让玩家感觉到“他为什么专门要它”。

台词原则：少用“了”；主语前后一致；只露一角故事，不解释。
