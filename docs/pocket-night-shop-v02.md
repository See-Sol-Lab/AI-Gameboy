# 口袋夜铺 v0.2：异物志

一位 AI 店主经营长期存档，人类网页只观看店铺、图鉴和回放。游戏不调用另一个模型来替玩家编结果，旧物、顾客和事件由本地规则与种子决定。

## 核心循环

淘货 → 首次发现记入异物志 → 修复揭秘 → 出售或回收换钱 → 解锁新地点。

- **异物志**：16 种旧物，分「已发现」与「已揭秘」。记录首次日期、地点、累计数量和已知秘密。出售、回收不删除记录；未知名字和秘密不会进观察响应。
- **街巷见闻**：5 类自动事件，收录遇见次数与玩家实际经历的结果。小事直接结算；包裹、小匣等选择事件交给 AI，结果在选择前保持隐藏。免费退出选项保证现金不足或满仓也能继续。
- **三处淘货点**：旧货巷、废弃车站、码头仓库。内容池和费用不同，只公开各地待发现种数。首次发现 4 种并付 8 枚可解锁车站；发现 8 种并付 12 枚可解锁码头。
- **稀有度**：寻常、少见、奇珍。重复发现计数；首次发现与首次揭秘各奖 2 枚，重复不再领取。
- **经营**：报价由 AI 决定，顾客隐藏预算、需求与旧物品质共同影响成交。回收可腾出货架；整理并承接街坊小修补收入 3 枚。打烊维护费为 2 + 店铺等级。

数据一律存在原有 SQLite 存档中。每次成功动作原子提交，批量命令也按一次事务提交完整结果，并逐班保留日志。没有真实时间惩罚：停止调用就停止游戏时间。

## AI 接入

网页建店使用 `solo_ai` 模式，只发出一份 AI 令牌。AI 用 `game_observe` 观察，再用 `game_act` 提交 `introduce`；介绍完成便自动开店，无需人类 START。

日常接口仍为 `game_observe / game_act`。令牌只交给店主，观看网页无需令牌。

| 动作 | 用途 |
|---|---|
| `work_shift` | 经营半日，`focus` 选择出售、修理、淘货、陈列、扩建、整理、回收或送客 |
| `run_shifts` | 连续淘货、修理或整理 1–6 班，逐班应用相同规则 |
| `choose_event` | 用当前 `event_id` 和 `choice` 回应选择事件 |
| `unlock_location` | 支付费用解锁达到收集门槛的地点 |
| `close_for_now` / `reopen_shop` | 随时歇业与续档，未决事件也完整保留 |

连续行动示例：

```json
{"focus":"scavenge","location":"station","count":4,"reserve":6,"stop_on":["new","rare","event"]}
```

- `stop_on` 默认为新发现、奇珍、事件；可传空列表略过普通播报停点。
- 需要 AI 决策的事件总会停下，即使 `stop_on=[]`。
- 库存满、修理完成、现金不足或扣除当班维护费后会低于 `reserve`，均在下一班开始前停下。
- 已完成班次保留；`last_run` 报告实际完成数、停止原因和新发现摘要。
- 出售、报价、回收珍藏不支持批量代决策。
- `mood / public_line` 完全可选。显示器自行展示行动与收支，AI 无需持续旁白。

每 7 个游戏日生成周账。图鉴集齐不是强制终局，仍可经营、收藏、维持顾客关系或自行歇业。

## 观看端

异物志、见闻录、淘货地图均可展开。已知条目可查看细节，未知内容保持遮蔽。

店况显示最新状态；经营回放标出所属日期与班次，每段至少停留 5 秒。可暂停显示器回放，AI 仍可继续经营。按日志序号分页补取，批量经营超过最近六条也不丢中间班次。网页不会要求人类处理事件。

## 旧档

0.1.0 规则原样归档，已有存档继续按旧版读取。店主可通过合法动作中的 `upgrade_shop` 显式升级：

- 同一存档、同一 AI 令牌，保留钱、时间、店铺、库存、目标、顾客关系与账本。
- 现存库存补入图鉴，已揭露秘密保留；不会凭空补造已卖出物品的完整发现史，也不重领首次奖励。
- 待开的旧门铃自动结算一次，结果进入公开日志。
- 升级后移除旧人类席的操作权限，观看者打开原网址仍可看公共店铺。
- 升级只在显式动作中、同一 SQLite 事务内完成；失败回滚，重复升级拒绝。

本轮开发验收没有修改任何真实旧局。

```text
python -m unittest discover -s tests -q
node --test tests/test_night_shop_ui.cjs
node --check web/app.js
```

另用只读取公开观察的固定策略做三组长期模拟（种子 11、29、73）：
三组均解锁全部地点，发现并揭秘全部 16 种旧物，遇见 5 类事件；在第 145、75、138 日完成，
关闭后 JSON 重载并重新开店，图鉴和未决事件一致。
这是可达性与存档验证，不等同于未读源码 AI 的趣味性盲测。
