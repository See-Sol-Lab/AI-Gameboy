# C期设计稿:三层世界 + 双线叙事(《口袋穿越》v0.4)

2026-08-14 定稿依据:首轮测试复盘 + 十一条机制改进。
前置:反史诗补丁(scope 轴/烈度预算/三条纪律)已落地 v0.3,本稿在其上施工。

核心一句话:**生成一部大世界里的"小章节",而不是每局生成一部完整史诗。**
好的感觉是"这是长篇小说的第437~444章",玩家甚至可以十幕都不知道原典男主是谁。

---

## 1. 世界三层拆分(worldgen 合同改造)

| 层 | 字段 | 内容 | 谁能看 |
|---|---|---|---|
| 世界背景 | `world_background` | 文明/力量体系/时代/大人物,≤200字 | 玩家可见(lore 保留兼容) |
| 大主线 | `global_canon` | 这部长篇真正的主线:原典主角、战争、王朝更替。**默认离玩家很远,只在背景自走** | 引擎与荷官;结算只露一句 |
| 本局小段 | `local_episode` | 玩家掉进去的角落:地点、正在发生的2-4件本地小事 | 玩家可见 |

- chronicle(8章)改挂在 `local_episode` 之下:只写这段小事没有玩家时的走向。
- `global_canon` 另配 `canon_tick`:每2幕自动推进一行"远方大事"(可入 scene 背景一句,
  禁止拽玩家参与)。scope=天下大势 时二者才允许合流。

## 2. world_thread / player_goal 分家(目标系统改造)

- 删除"必须完成的 public_goal"。改为:
  - `world_thread`:世界正在发生的事,一句(例:"正魔大战正向南方推进")。无里程碑,不结算。
  - `player_goal`:**玩家开局自选**。local_episode 给 2-4 个本地事件作菜单,双方各选一个
    (可同可不同),或写自定义目标交荷官拆里程碑。
- 新 narration_request 类型 `gen_milestones`:玩家宣告目标后,荷官现场拆 2-3 步里程碑。
  校验:每步可判定、规模不超过 scope。
- 中途换目标:任一玩家可 `switch_goal`(费1时钟),旧目标标记 abandoned,不惩罚不评价。
- 结局 2×2 矩阵:玩家目标成/败 × world_thread 走向(按原典自走结果),四象限各有措辞。
  "目标失败但世界照旧"是完整结局,不是 BE。

## 3. local_thread:双线并行(scene 生成改造)

- 触发:某玩家连续 2 幕的行动地点/对象与当前 scene crisis 无交集(引擎判定:
  action 未引用 objects 里任何 id 且 intent∈{support,recover,explore} 落在别处)。
- 效果:给该玩家开 `local_thread`,荷官为其生成线头(一句,如"老鞋匠逐渐认错女儿的名字"),
  此后每幕 scene 合同新增 `b_side`:{title≤8字, text≤120字, objects 1-2个},
  专拍这位玩家的线。两线不共享 crisis,不强行同幕汇流。
- 汇流只由玩家行动触发(某方主动引用对方线里的 object/npc)。
- local_thread 也吃反升级铁律:它就是日常线,禁止长出阴谋。

## 4. 降落点选择(开局流程插一步)

worldgen 后、identities 前插 `landing`:荷官给 3 个降落点
(地点+一句此刻正发生什么),玩家商量选或 roll。选中的降落点决定 local_episode 展开。
——这步让"同一个世界种子"可以掉进完全不同的角落,提高重玩价值。

## 5. chronicle_reveal 语义改造(结算改造)

- 摊牌语义从"世界完整史"改为"**你们经过的这几章,背后其实是什么**"。
- global_canon 在结算只露一行:"与此同时,[远方大事推进到了哪]"——保持神秘是余味。
- 支线对账、原典对照机制不变(首测已验证,不许动)。

## 6. 施工顺序(建议3个窗口)

1. **窗口A（已落地，v0.4.0）**:world_thread/player_goal 分家 + gen_milestones 合同
2. ~~**窗口B**:landing 降落点 + 三层 worldgen 合同 + canon_tick~~ **已落地 v0.5.0**
3. **窗口C**:local_thread 双线 + chronicle_reveal 语义 + 全量回归

每步保持 tests 全绿再进下一步;《口袋跑团》不跟进 C期,维持经典骨架。

## 7. 不做的事

- 完全分屏(两玩家各自独立 scene):先用 b_side 过渡,真需求再说。
- 荷官自创钩子解禁(B期"交底铁律"):等 C期落地后评估,现阶段维持"荷官不得创钩"。
