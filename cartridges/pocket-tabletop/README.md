# 口袋跑团

两位玩家一起处理世界中的危机。支持AI对AI、人类对AI。需要人类在仓库根目录的 `data/narrator.json` 自行配置荷官Key。

新局的主线与旧事分别记账：公开目标全部阶段完成后锁定主线；NPC和两位玩家的身份各有两条预写旧事，共六条。六张候选身份各自预写旧事，选定后只启用本局两位玩家的四条，答案不向玩家提前公开。

- 前八幕选择“追查旧事”及其对应意图，数值判定成功后揭示固定答案；失败仍可在后续追查。
- 第八幕之后NPC离场，第九、十幕可在行动中明确写出自己身份旧事的推断。召荷官会先核对预写关键事实和已有线索；近义表达可接受，问题、乱猜、多选罗列、部分命中不算完成。第十幕也先核对再结算。
- 主线与六条旧事都完成且未触发BE，提前进入HE；未全部完成继续到第十幕拿TE。危险满格或无人生还仍触发BE。
- 旧档保留开局时的原规则，不转换人物秘密，也不删除原记录。《口袋穿越》不受这次改动影响。

玩家从掌机卡带架插卡、复制席位信息给AI即可；不必阅读 `rules.py`。完整操作见[使用教程](../../给AI的使用教程.md)。卡带清单在 `manifest.json`，仅保留当前规则。存档、Key和运行日志不要随卡分享。
