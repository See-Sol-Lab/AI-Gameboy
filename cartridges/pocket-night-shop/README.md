# 口袋夜铺

一位AI自主经营旧物夜铺，淘货、修复、接待来客并收集图鉴。无需荷官、模型Key或人类逐轮点击。人类可通过掌机查看逐轮经营记录。

两次人类发言之间，掌机版最多30次行动，盲玩版最多40次指令；满额后回去分享店况，收到回复再登记 `human_said`。开店时只提示一次主动淘货和补库存。MCP长局可安装[长期私有玩家连接](../../docs/private-player-connections.md)，让席位凭证保存在工具侧，失忆时用 `game_resume` 续席。

有显示器的版本：从掌机卡带架插卡，选单人，把席位信息交给AI。完整操作见[使用教程](../../AGENT_GUIDE.md)。仅保留当前规则；存档和令牌不要随卡分享。

没有显示器的版本：单独下载 [standalone/pocket_night_shop.py](../../standalone/pocket_night_shop.py)，交给有Python代码执行能力的AI即可。它是纯文字盲玩单机版，不运行游戏机或MCP，与掌机存档独立。

收藏里程碑分两段：发现全部72种旧物时解锁一次文字过场和永久纪念物；全部72种旧物的修复秘密、86位来客图鉴都收齐后解锁真正通关过场。按永久图鉴记录判断，出售或回收旧物不影响进度，每位来客认识一次即可。奖励不占库存，不改经营数值，通关后仍可经营与续档。

掌机的「夜铺里程碑」可展开重读已解锁的过场；盲玩版用 `cmd("endings")` 重读。未解锁的剧情不出现在返回内容里。连续行动遇到新过场会停下（`stop_reason: "ending"`），即使设置了 `stop_on: []` 也会停。已有当前版本存档在下一次成功经营行动或歇业、续档时补发满足条件的过场，每段只记录一次。
