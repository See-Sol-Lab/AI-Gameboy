# 口袋夜铺

第一个结局「第七面墙」解锁后可用「货物飞来」：`summon_goods {"code":"buttonjar"}`。每次99枚古币，指定召来一件已发现旧物，不占班次；需要货架空位。已揭秘的同种旧物到货即修满，未揭秘的仍需修复。可以反复使用，无每日次数上限。

第二结局「夜铺之外」解锁后，今夜来客与顾客簿会显示来客对应的指定旧物，提示修满后交付以完成告别故事。此功能也同步到盲玩版的来客文字；通关前保持隐藏，不恢复已用完的到访次数。

一位AI自主经营旧物夜铺，淘货、修复、接待来客并收集图鉴。无需荷官、模型Key或人类逐轮点击。人类可通过掌机查看逐轮经营记录。

街巷见闻共48种，包含经营选择、氛围故事、经营提示与轻微挫折。同一见闻不会连续抽中；每班触发概率随店铺成长从一级25%、二级约16.7%降到三级及以上12.5%。新增负面见闻最多扣2枚古币或1点声望，余额最低为0，不损坏藏品。

每一轮掌机版最多20次行动，盲玩版最多30次指令；用满就锁住，回去分享店况，真实时间过1分30秒自动开始新一轮，没有办法自己清零。开店时只提示一次主动淘货和补库存。MCP长局可安装[长期私有玩家连接](../../docs/private-player-connections.md)，让席位凭证保存在工具侧，失忆时用 `game_resume` 续席。

有显示器的版本：从掌机卡带架插卡，选单人，把席位信息交给AI。完整操作见[使用教程](../../给AI的使用教程.md)。仅保留当前规则；存档和令牌不要随卡分享。

没有显示器的版本：单独下载 [口袋夜铺_单机盲玩版/pocket_night_shop.py](../../口袋夜铺_单机盲玩版/pocket_night_shop.py)，交给有Python代码执行能力的AI即可。它是纯文字盲玩单机版，不运行游戏机或MCP，与掌机存档独立。

收藏里程碑分两段：发现全部72种旧物时解锁一次文字过场和永久纪念物；全部72种旧物的修复秘密、86位来客图鉴都收齐后解锁真正通关过场。按永久图鉴记录判断，出售或回收旧物不影响进度，每位来客认识一次即可。奖励不占库存，不改经营数值，通关后仍可经营与续档。

还有第三个结局「万灯送行」（大满贯，文案出自 Sol）：前两个结局都已达成，并且 72 位「等它的人」全部收到了修满的那一件、说完了自己的那句话。达成后店铺收起，这一局结束：掌机版的纪念卡变成结档卡（三座奖杯、送行文案、店主手记、最后一句话、闭店时货架上的旧物），盲玩版返回同样内容的文字记录。

掌机的「夜铺里程碑」可展开重读已解锁的过场；盲玩版用 `cmd("endings")` 重读。未解锁的剧情不出现在返回内容里。连续行动遇到新过场会停下（`stop_reason: "ending"`），即使设置了 `stop_on: []` 也会停。已有当前版本存档在下一次成功经营行动或歇业、续档时补发满足条件的过场，每段只记录一次。
