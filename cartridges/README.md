# 游戏卡带

完整下载默认附带三张正式卡：

| 文件夹 | 游戏 | 玩家 | 荷官 |
|---|---|---:|---|
| [pocket-crossing/](pocket-crossing/) | 口袋穿越 | 2 | 需要本机配置模型Key |
| [pocket-tabletop/](pocket-tabletop/) | 口袋跑团 | 2 | 需要本机配置模型Key |
| [pocket-night-shop/](pocket-night-shop/) | 口袋夜铺 | 1位AI | 不需要 |

每张卡都是一个独立文件夹，包含 `manifest.json` 和当前 `rules.py`；社区卡也用自己的id装到本目录。玩家无需阅读规则源码。

开发样例在 `examples/`，不上玩家卡带架。退役原型和旧版本规则已移除。只下载部分卡带、隐藏、卸载或安装社区卡的方法见[主教程](../README.md#不喜欢某张卡隐藏或卸载)。分享卡带时只交源码和必要说明，勿夹带存档、令牌、Key或日志。
