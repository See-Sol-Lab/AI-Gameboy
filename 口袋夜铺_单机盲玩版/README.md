# 单文件游戏：纯文字盲玩，无掌机显示器

下载 `pocket_night_shop.py` 一个文件即可玩夜铺。需要有Python代码执行能力的AI和Python 3.11+，不需要游戏机、MCP、模型Key或第三方依赖。

与掌机版共用48种街巷见闻：新增12种氛围与经营提示、12种轻微负面见闻。同一见闻不会连续抽中，每班触发率从一级店25%、二级约16.7%降至三级及以上12.5%；新增扣款最多2枚古币、扣声望最多1点，余额最低为0。

**人类旁观体验：** 如果AI客户端不展示思考过程（“思维链”），又折叠了工具输出，你通常只能看到AI暂停后分享的结果，难以实时看到它每班接待了谁、做了哪些选择。盲玩版因此更适合让AI自行经营，不影响它探索或续档，但人类参与感会较弱。想“偷看”开店过程的人类，有条件时建议让本机Agent启动[完整游戏机](../README.md#一游戏机)，从掌机网页查看公开的逐轮行动、来客互动、历史与图鉴，无需AI每轮解说。掌机也不展示AI的内部思维链。

```python
import pocket_night_shop as shop
print(shop.cmd("help"))
print(shop.cmd("observe"))
```

Windows 上如果 `python` 只会打开应用商店（那是系统自带的占位程序），改用 `py -3`；命令行输出乱码时先设 `PYTHONIOENCODING=utf-8`。

请通过指令探索，勿解码内置规则或读取隐藏存档字段。包装防止误读剧透，不是加密。每次行动自动存到同目录的 `pocket_night_shop.save.sqlite3`；下次 `observe` 接档。

**第一次玩**：头两周建议一班一班地 `work_shift` 淘货，一件旧物、一位客人慢慢认识；别一上来就开 6 班连淘速刷，熟悉以后再用 `run_shifts` 省事。

**调用上限**：每轮最多调用 `cmd` 30 次，连淘每次最多6班。用满后锁定90秒真实时间，请停下来分享店况并结束回复；90秒后自动开始新一轮。两次调用本来就相隔90秒以上，也算新一轮。`human_said` 已取消，不能自行填人类原话清零，也不要写等待脚本绕过停顿。

**当前流程**：一天五班，下午两班不接客、淘货半价，傍晚两班和深夜接客，深夜结算。回收可得星沙，重复货可拆件修理，部分见闻会给限时传送卷轴；详细写法以 `help`、`observe` 为准。地图中的旧物全部修好并交到等待的人手里后，该市场关闭。玩法参数与掌机卡带共用同一规则来源，存档仍各自独立。

本版**没有掌机网页**，也不连接游戏机存档。需要人类旁观显示器时，请安装[完整游戏机](../README.md#一游戏机)。

**三个结局**：发现72种旧物解锁「第七面墙」；72种全部修满揭秘解锁「夜铺之外」，不要求全部来客图鉴；再将对应的修满旧物交给全部72位「等它的人」，达成「万灯送行」并结档。每位来客最多到访8次，大满贯可能错过；前两个结局仍可正常完成。

「第七面墙」后可花99古币用 `summon_goods {"code":"buttonjar"}` 指定召货，不占班次；「夜铺之外」后能看到当前来客对应旧物，并用 `exchange_resources {"resource":"stardust","amount":50}` 换钱：1星沙换2古币，1声望换1古币（声望用 `reputation`）。无对应旧物的客人直接说明收货类别，不显示线索。
